# .github

Org-wide defaults for the [rmx-lt](https://github.com/rmx-lt) repos of **Blade of Grass**: the pull request template every repo uses unless it has its own.

Docs: the [wiki](https://github.com/rmx-lt/blade-of-grass/wiki), rules in [Wiki-Policy](https://github.com/rmx-lt/blade-of-grass/wiki/Wiki-Policy). Work: the [project board](https://github.com/orgs/rmx-lt/projects/1).
